            OrganPipe — Flag Reference
            
          

          

            

              
                

                  Flag
                  Type
                  Description
                

              
              
                

                  -d <path>
                  Required
                  Path to your working directory where all workflow files are
                

                

                  -c <path>
                  Required
                  Config file path (YAML or CSV) with all needed parameters
                

                

                  -t <int> / -j <int>
                  Required
                  Number of threads (local mode) or jobs submitted at once (SLURM mode). Use -t for
                    local runs; when using -slurm, use -j to control SLURM job concurrency
                  
                

                

                  -np
                  Optional
                  Dry run — shows what jobs will be executed without running them. Also builds Singularity images
                  
                

                

                  -unlock
                  Optional
                  Unlock the working directory if Snakemake has locked it after a crash. Run once with this flag,
                    then remove it and run normally
                

                

                  -batch
                  Optional
                  Enable batch mode for large runs (> 3000 rules / many samples). Improves Snakemake DAG
                    resolution time
                

                

                  -nbatch <int>
                  Optional
                  Number of batches when using -batch (default: 5)
                

                

                  -sifdir <path>
                  Optional
                  Directory to build/cache all Singularity image files. If images already exist, they won't be
                    re-pulled. Default: resources/sif_dir
                

                

                  -rerun
                  Optional
                  Delete previous results and temporary files for all samples in the config file to ensure a clean
                    re-run with updated configurations. No arguments needed.
                

                

                  -nhmmer_db <path>
                  Optional
                  Path to HMMER database for nhmmer. Defaults to resources/rfam.hmm. Must be HMMER v3.4
                    compatible
                

                

                  -slurm
                  SLURM
                  Enable SLURM job submission mode using Snakemake's profile system
                

                

                  -j <int>
                  SLURM
                      only
                  Number of jobs to submit to the SLURM queue at once. Use alongside -t when running in
                    SLURM mode
                

                

                  -partition <name>
                  SLURM
                      only
                  SLURM partition (queue) to submit jobs to. Required when using -slurm
                

              
            

          

          
To customize default thread counts and memory per rule, edit
            config/local_params.yaml. Do not modify the {WORKDIR}, {THREADS}, or
            {PARTITION} variables directly.

            PIMBA — Flag Reference
            
          

          

            

              
                

                  Flag
                  Type
                  Description
                

              
              
                

                  -d <path>
                  Required
                  Working directory containing the cloned pimba_smk repository
                

                

                  -c <path>
                  Required
                  Path to the configuration YAML file (e.g. config/config.yaml)
                

                

                  -p <mode>
                  Required
                  Read preparation mode: paired_end, single_index, dual_index, or no
                

                

                  -r <db>
                  Required
                  Reference database for taxonomic assignment: COI-BOLD, COI-NCBI, 16S-SILVA, 16S-GREENGENES, 16S-RDP, 16S-NCBI, ITS-PLANTS-NCBI, ITS-FUNGI-UNITE, ITS-FUNGI-NCBI, ALL-NCBI, or Custom
                

                

                  -g <yes|no>
                  Required
                  Enable diversity and abundance visualization plots
                

                

                  -l <yes|no>
                  Required
                  Enable phylogenetic placement of unclassified sequences (EPA-ng)
                

                

                  -t <int>
                  Required
                  Number of CPU threads for parallelizable tasks
                

                

                  -u
                  Optional
                  Unlock the Snakemake working directory after a crash. Run once, then remove before re-running
                

              
            

          

          
Configure input file paths, adapter sequences, and database paths in config/config.yaml before running. Always use absolute paths in the config file.
