Available pipelines

OrganPipe

Iterative assembly and annotation of organellar genomes (plastomes and mitogenomes) from Illumina short reads and PacBio/ONT long reads — using NOVOPlasty, GetOrganelle, and MitoHifi with multiple seeds and k-mer combinations for high-accuracy results.

Open configuration

Pipeasm

Streamlined genome assembly following the VGP and DToL reference-quality standards. Written in Snakemake with Docker and Singularity support, Pipeasm automates the full assembly workflow from raw reads to polished, scaffolded assemblies.

Open configuration

ProCura

Modular genome curation and evaluation pipeline for diploid assemblies. Runs in three modes — hapcuration, dualcuration, and finalgenome — using Snakemake and Singularity to deliver reproducible, scalable quality control and validation.

Open configuration

PIMBA

PIpeline for MetaBarcoding Analysis — an open-source Snakemake workflow supporting OTU- and ASV-based strategies, multiple reference databases, and automated downstream analyses across three modules: Main Workflow, Tax reassignment, and Curate.
