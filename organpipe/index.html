Project Information

Identify your sample and sequencing setup

The name of the sample to process. Use all to process every sample found in the reads_path directory automatically. Read filenames must include delimiters like _R1/_R2 or _pair1/_pair2 to distinguish paired-end reads. For short reads, ensure only .fastq.gz files are present in the reads directory.

Directory path containing your sequencing read files. For short reads: only .fastq.gz files should be present. For long reads: files can be .fasta or .fastq.gz. The pipeline will scan this directory for all matching files.

Type of organelle genome to assemble. Choose Mitochondrial (mito) for mitochondrial genome assembly — supports both short and long reads. Choose Chloroplast (chloro) for plastome assembly — only Illumina short reads are supported for chloroplast.

Chloroplast assembly only supports Short (Illumina) reads.

NCBI translation table number used for mitochondrial genome annotation. This defines which codon table is applied when translating CDS features. Common values: 1 = Standard (most eukaryotes, nuclear genomes), 2 = Vertebrate Mitochondrial (fish, amphibians, reptiles, birds, mammals), 5 = Invertebrate Mitochondrial (insects, worms, molluscs, most invertebrates), 11 = Bacterial, Archaeal & Plant Plastid (chloroplast annotation). See NCBI Genetic Codes for the full list.

Type of sequencing technology used. Choose Short reads for Illumina data (.fastq.gz). Choose Long reads for PacBio or ONT data (.fasta or .fastq.gz). Note: chloroplast assembly only supports short reads; long reads are only supported for mitochondrial assembly.

Quality Control

Adapter trimming and read filtering

Fastp / Cutadapt

Run Fastp for adapter trimming and quality control on short reads. For long PacBio reads, Cutadapt is used instead (only .fastq.gz is supported for long-read trimming). Select No to skip this step and proceed directly to assembly with raw reads.

Path to a plain-text file listing adapter sequences to be removed by Fastp, one per line. Leave blank to let Fastp auto-detect adapters from the reads — this works well for most standard Illumina libraries. Only applicable for short reads.

Reads shorter than this length (in bp) after trimming will be discarded. Typical values: 50–100 bp.

Minimum Phred quality score (Q-score) for base trimming. Bases below this threshold are trimmed. Common value: 20 (Q20 = 99% accuracy).

Cutadapt adapter arguments for PacBio long-read trimming. The default values are the standard PacBio SMRTbell adapter sequences. Files must be in .fastq.gz format for this step. Modify only if you are using custom or non-standard adapters.

Pipeline Steps

Configure annotation, nhmmer search, and visualization

Run the annotation pipeline for the assembled organelle genome. Uses MITOS for mitochondria and GeSeq / PGA for chloroplast. For long-read mitochondrial data, annotation is handled automatically by MitoHifi.

Run nhmmer to identify non-coding RNA (ncRNA) features and intergenic regions in the assembled genome using profile Hidden Markov Models (HMMs) against the Rfam database. Useful for annotating tRNAs, rRNAs, and other structural RNAs missed by standard annotation. The HMM database is provided with the -nhmmer_db flag when executing the pipeline.

Generate visualizations for the assembled genome, including OGDraw circular genome diagrams, read depth coverage plots, and recruitment plots. Only supported for short-read assemblies. Not available for long-read data.

NOVOPlasty Assembly

Seed-based organelle genome assembler — short reads only

NOVOPlasty

Run NOVOPlasty for organelle genome assembly. NOVOPlasty is a seed-and-extend assembler designed specifically for organelle genomes that works directly on raw Illumina reads. At least one of NOVOPlasty or GetOrganelle should be enabled.

Optional. Path to a reference genome in FASTA format. NOVOPlasty uses this as a guide to resolve duplicated regions in plant mitochondria or the inverted repeat (IR) in chloroplasts. If not available, leave blank and use a seed file or NCBI search instead.

Seed Configuration

Format of the seed file used to initialize NOVOPlasty assembly. The seed should contain a known gene or sequence from the target organelle. Choose FASTA for a plain sequence file, or GenBank to use a GenBank-annotated file (you will then specify which feature type to use). Leave as None if you want to fetch seeds automatically from NCBI. For long-read sequencing, leave this blank and use Search NCBI.

Path to the seed file in the format selected above. The seed should be a short sequence (e.g., a mitochondrial gene) from a closely related organism.

Feature type to extract from the GenBank seed file for assembly initialization. CDS = protein-coding sequences, rRNA = ribosomal RNA genes, tRNA = transfer RNA genes.

NCBI Search Use when no seed file is available — set Seed Format to None

Automatically search and download reference sequences from NCBI to use as seeds for assembly. Requires internet access. Set Seed Format to None when this is enabled. For long reads, this must be set to Yes. Set to No if you are providing a local seed file above.

Comma-separated list of gene names to query on NCBI. These genes will be used as seeds for assembly. Examples for mitochondria: COI,16S,ATP6. Examples for chloroplast: rbcL,matK,trnL. At least one gene is required when NCBI search is enabled.

Taxonomic name used as the NCBI query (e.g., Amphisbaena, Homo sapiens). Narrows the search to sequences from related species.

Maximum number of reference sequences to download from NCBI per gene. Higher values increase coverage but slow download. Typical: 3–10.

Assembly Parameters

Expected genome size range in base pairs. NOVOPlasty uses this to determine when assembly is complete. Typical ranges: 15000–18000 for animal mitochondria, 200000–650000 for plant mitochondria, 130000–160000 for chloroplast. Format: min-max.

Comma-separated list of k-mer sizes for the assembly graph. NOVOPlasty will try each k-mer size. Smaller k-mers improve sensitivity for low-coverage regions; larger k-mers improve specificity. Recommended: 19,23,33 for standard Illumina libraries.

Maximum RAM (in GB) allowed during assembly. Set this to the available memory on your system to prevent out-of-memory errors.

Sequencing read length in base pairs. For Illumina: typically 100, 150, or 250 bp. Check your sequencing report if unsure.

Average insert size of the sequencing library in base pairs — the distance between the two paired-end read adapters. Typical values: 300–500 bp for standard paired-end libraries. Check your library preparation protocol or sequencing QC report.

GetOrganelle Assembly

Graph-based organelle assembler — short reads only

GetOrganelle

Run GetOrganelle for organelle genome assembly. GetOrganelle uses an iterative read-enrichment and graph-based approach to assemble organelle genomes from Illumina short reads. It can handle multi-organelle assembly and complex repeat structures. Can be run alongside NOVOPlasty for cross-validation.

The organelle-type database flag used by GetOrganelle (-F option). Select the type that matches your target organelle: embplant_pt (land plant plastome), other_pt (non-land plant plastome), embplant_mt (plant mitogenome), embplant_nr (plant nuclear rDNA), animal_mt (animal mitogenome), fungus_mt (fungal mitogenome), fungus_nr (fungal nuclear rDNA). Multiple types can be combined with commas (e.g., embplant_mt,other_pt).

Maximum number of read-enrichment rounds (-R). Higher values assemble more of the genome but take longer. Defaults: 15 (embplant_pt), 30 (embplant_mt / other_pt), 10 (animal/fungus/nr). Minimum recommended: 2.

Hypothetical target genome size used to estimate word size (-t). Defaults: 130000 (embplant_pt), 390000 (embplant_mt), 13000 (animal_mt), 65000 (fungus_mt). For multi-organelle mode, provide a comma-separated list matching each database type.

K-mer sizes for the internal SPAdes assembler, in the same format as SPAdes (-k). Comma-separated list, e.g., 21,55,85,115. Using a range of k-mer sizes improves assembly quality across varying coverage regions.

Any additional command-line flags to pass directly to the GetOrganelle command. Use this for advanced tuning not covered by the options above. Refer to the GetOrganelle documentation for available flags.

MitoHifi Assembly

Long-read mitogenome assembler — long reads + mito only

MitoHifi

Taxon name used to search NCBI for complete mitogenome reference sequences for MitoHifi assembly (e.g., Amphisbaena, Homo sapiens). MitoHifi requires a closely related complete mitochondrial genome as a reference to guide assembly from long reads. This should be a genus or species name present in NCBI.

Maximum number of complete mitogenome reference sequences to download from NCBI per search. More references improve the probability of finding a suitable guide genome, but increase download and processing time. Typical value: 3–10.
