4

Advanced Tool Parameters

The defaults work for most genomes. Each value is passed as-is to the tool's command line.

BWA-MEM2 · pairtools · PretextMap
FastK

-v: verbose; -M32: up to 32 GB of memory for sorting; -t1: keep k-mers seen at least once.

K-mer size used by FastK and MerquryFK, e.g. 31.

BWA-MEM2

-S: skip mate rescue; -P: skip pairing, so each read of a pair is aligned on its own, as required for Hi-C; -T0: output all alignments (pairtools filters them).

pairtools

Alignments with a lower mapping quality are treated as multimapping.

--walks-policy 5unique: 5'-most unique alignment of each side; --max-inter-align-gap 30: longer unaligned stretches are unmapped segments.

PretextMap

Sets the resolution argument in PretextMap flags. Open --ultraRes maps in a recent PretextView (1.x).

Sorting and resolution. The mode default is applied automatically.
